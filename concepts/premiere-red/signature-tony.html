How to install

  1. Apple Mail: Mail → Settings → Signatures → add a new signature, then click inside the signature box and paste (Cmd+V). If Mail strips formatting, uncheck “Always match my default message font”.
  2. Gmail: Settings (gear icon) → See all settings → General → scroll to Signature → Create new → click inside the empty editor and paste (Cmd+V) → Save Changes.
  3. Outlook: Settings → Mail → Compose and reply → paste into the signature box, or in desktop Outlook: File → Options → Mail → Signatures → New → paste.
