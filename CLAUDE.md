# Gattillo Global Website

Strategic presentation platform for Gattillo Global's innovation pitch to Chinese manufacturers and stakeholders.

## Project Overview
- **Main presentations**: `index.html`, `gattillo-china-innovation-deck.html`
- **Design system**: Uses V-Data components (stored in ~/Documents/Reference/V-Data/)
- **Assets**: Logos, images in `assets/` and `car-ev-logos/`
- **Concepts**: Design variations in `concepts/` folder

## Key Features
- Interactive HTML presentations that run on localhost
- Shareable via GitHub (can be published as GitHub Pages)
- Python PPTX converter available (`convert_to_pptx.py`)

## Recent Work
- Created China innovation deck for arcade manufacturers
- Set up deployment on GitHub
- Working on making presentations accessible and shareable

## For Claude Code
When working on this project:
- Run presentations on localhost:8888
- Refer to V-Data for design components and themes
- Keep git history up to date (`.git` folder present)
- HTML files are presentation source (not static docs)
